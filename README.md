# Find-the-largest-number-50

Find Largest Number

Description

This is a simple HTML and JavaScript program that asks the user to enter two numbers and then determines which number is the largest.

The program uses JavaScript's "prompt()" function to get the numbers from the user and "if...else if...else" statements to compare them.

How to Use

1. Open the HTML file in a web browser.
2. Click the Press Here button.
3. Enter the first number when prompted.
4. Enter the second number when prompted.
5. The program will display an alert showing which number is larger.
6. If both numbers are the same, the program will display that the numbers are equal.

Example

If the user enters:

First number: 5
Second number: 10

The program displays:

The second number is larger.

If the user enters:

First number: 10
Second number: 10

The program displays:

Both numbers are equal.
